# Wael Awathi — Portfolio

Portfolio personnel responsive de Wael Awathi, technicien supérieur en informatique de gestion.

## Technologies
- HTML5
- CSS3 (responsive design, animations)
- JavaScript (menu mobile, animations au défilement)

## Lancer le projet
Ouvrir simplement `index.html` dans un navigateur.

## Déploiement GitHub Pages
1. Ouvrir **Settings → Pages** dans le dépôt GitHub.
2. Dans **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche `main` et le dossier `/(root)), puis enregistrer.

Le site sera publié à l'adresse :
https://waelawathi5.github.io/my-portfolio/

## Personnalisation
Mettre à jour les textes, projets et liens dans `index.html`. Les styles sont dans `style.css` et les interactions dans `script.js`.
